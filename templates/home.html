Privacy & Security

🔍 How do I know I can trust you?

Short answer: You cannot.
Transparency is key: this project is experimental. While functional, much of the logic was synthesized by LLMs. I encourage you to audit the source code thoroughly before deployment to ensure it meets your personal security standards.

🔑 Passwordless Security

Experience seamless login with Passkeys.

🎯 Purpose-Built Focus

A minimalist task tracker built for deep work.

🧬 WebAuthn PRF

Implementation complete. WebAuthn PRF enables symmetric key generation using Authenticators/Passkeys.

🛡️ Privacy by Design

Your data is protected by hardened security headers and modern session encryption protocols.

⚡ End-to-End Encryption

Full E2EE for your data. Keys are currently managed via session storage; therefore, defense relies heavily on strict XSS prevention.
Note: Only task labels and comments are encrypted.

🧪 Known Anomalies

In some environments, the primary administrative account may experience persistence issues during the initial session. I am investigating the root cause of this authentication edge case to ensure total stability across all instances.
